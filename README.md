  LifeLink 🩸
  
  Life Link provides a Web-based solution for improving blood donation coordination. 
  By connecting donors, hospitals, and blood banks in one platform,it reduces delays during emergencies and increases access to life-saving blood supplies.
  The system aims to create a faster, safer, and more reliable blood donation ecosystem.

  Project Objective
The main objective of LifeLink is to improve the coordination of blood donation and distribution by reducing delays between hospitals, blood banks, and potential donors.
- Key Features
- Hospital Requests — Hospitals can submit requests for required blood types and quantities.
- Blood Inventory Management — Blood banks can monitor and manage available blood units.
- Donor Management — Donors can register and maintain their information.
- Donor Notifications — Eligible donors can be contacted when their blood type is needed.
- User Authentication — Secure access based on user roles.
- Dashboard System — Separate dashboards for administrators, blood banks, hospitals, and donors.
- Blood Availability Tracking — Helps determine whether requested blood is currently available.
- Centralized Coordination — Connects the major participants in the blood donation process.

- Tech Stack

- Frontend - HTML5, CSS3, JavaScript 
- Backend - Node.js, Express.js, Prisma, PostgreSQL
- Version Control - Git, GitHub 


  Getting Started
1. Clone the repository
git clone https://github.com/19mekdes/LifeLink.git
Replace the repository URL above with the LifeLink repository URL when available.
2. Navigate to the project
cd LifeLink
3. Install dependencies
npm install
4. Start the development server
npm start
The application can then be accessed through the local address provided by the server.
